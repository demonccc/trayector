# Manage site publication

Use .trayector/settings/site.yaml to enable optional sections and select one published CV by slug (`cv.selected`). Keep site implementation in the central Trayector release, not the personal profile. The release-pinned reusable publish workflow renders Markdown to HTML and selected CV to PDF; changing the selected CV must not regenerate its content using AI. Check the selected Markdown exists before enabling CV publication. Do not publish drafts, private documents or unsolicited data.
