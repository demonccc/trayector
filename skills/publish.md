# Manage site publication

Use `.trayector/settings/site.yaml` to enable optional sections and select the CV by slug (`cv.selected`). Site `languages` lists the language versions that the website is allowed to expose; articles may have additional language files, and no translation is generated automatically. This setting is about website output, not the author's professional language skills or a global writing language. Articles are opt-in: publish only directory slugs explicitly listed in `articles.include` when the site and article section are enabled. The human-readable `articles/<slug>/README.md` indexes language files; every linked Markdown body is free-form. Never publish an unlisted article or silently enable new articles. Keep site implementation in the central Trayector release, not the personal profile. The release-pinned workflow renders Markdown and the selected CV to PDF without AI content generation. Verify sources and get explicit publication authorization.
