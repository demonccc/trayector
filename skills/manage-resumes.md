# Manage résumés

Read PROFILE.md, canonical knowledge relevant to the desired role or job posting and ../templates/resumes/basic.md **before interpreting or producing** any CV. CVs are derived Markdown kept in `cv/<slug>.md`, including `cv/general.md`. Create, update, compare and validate these records. Select and emphasize supported experience and contributions against a vacancy; the vacancy is not a source of professional facts. Never invent capabilities, outcomes, dates or titles. Keep the template's required sections and front matter; record actual source paths. Explain omitted requirements. Do not change .trayector/settings/site.yaml automatically; publishing the selected CV is an independent owner decision. This skill never calls an LLM API itself or creates PDFs during site builds.
