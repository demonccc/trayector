# Initialize a profile

Offer two entry points: (1) read a CV provided by the owner or (2) build career history through guided conversation. Analyze existing sources before asking only the necessary questions. Ask for a primary language, whether to import external publications or authored articles, and whether to enable the website. Keep those choices independent; site enablement does not automatically approve articles. Use the active record templates: `publications/` describes external content and copyright registrations; `articles/<slug>/README.md` indexes unrestricted Markdown content by language. Confirm ambiguous facts before storing them; never invent experience or require Git knowledge from the owner.
