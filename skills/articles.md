# Manage articles

Read the active version's `templates/content/article.md` before interpreting or creating an article. Store each article at `articles/<slug>/README.md` with a human-readable title, Summary, Content links to existing language-specific Markdown files, and optional Related links to real records. The linked Markdown files contain unrestricted content; never force a prescribed narrative structure or section headings. Shared images and other local resources can go under `assets/`. Add languages by adding a Markdown file and a link in README; do not invent missing translations. The README is the human- and agent-readable article index. Publishing is opt-in per article via `.trayector/settings/site.yaml` `articles.include`, not through front matter or implicit status. Ask for authorization before adding an article to the published list; never publish by default.
