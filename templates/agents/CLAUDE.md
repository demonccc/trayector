# Trayector Career as Code

Professional profile entry: `PROFILE.md`.

Before any career work:
1. Read `.trayector/settings/trayector.yaml` and obtain the top-level `version`.
2. Read `.trayector/versions/<version>/skills/index.md`.
3. Load the corresponding template under `.trayector/versions/<version>/templates/` **before reading or writing** any professional record; it is a mandatory structural contract.
4. Follow the applicable operational skill and profile-rules.md.

Owner-defined custom instructions are not automatically loaded.
