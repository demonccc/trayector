## Template rules

This is a **presentation template**, not a source of professional facts.

When generating a tailored résumé:

- read the target job description first;
- read the canonical Trayector profile before drafting;
- select and reorder only supported information;
- prefer evidence-backed claims;
- use the language of the target role only when it remains faithful to the source meaning;
- do not invent missing requirements;
- do not inflate titles, seniority, scope, metrics or ownership;
- keep irrelevant detail out even if it exists in the profile;
- keep the result readable by both humans and ATS systems.
