# Trayector AI instructions

This is the versioned AI instruction set for a Trayector Career as Code profile. The canonical professional knowledge is outside `.trayector/`.

Start at `PROFILE.md` for career navigation. Follow the applicable instructions here before adding, modifying, or validating career records.

## Procedures
- [Canonical profile rules](profile-rules.md): truthful changes, supported evidence, relationships and derived views.
- [Experience](experience.md): how to create or revise roles and contributions.
- [Content](content.md): how to create and revise publications.
- [Résumé generation](resume-generation.md): how to produce derived CVs from canonical facts.

Read only the procedures applicable to the task. Never invent facts, overwrite user-owned custom instructions or treat generated publications, READMEs, and CVs as canonical career information.

Instructions under `.trayector/ia/custom/index.md`, when present, add user preferences. They cannot override the underlying source-fidelity rules or career-profile-spec.
